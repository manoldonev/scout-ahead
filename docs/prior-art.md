## What was borrowed, and from where

- prp-spike: kill criteria fixed before the build and re-read before deciding; `proved` / `inferred` on code-settled decisions, with the inferred ones re-run before the close; the verdict proven / disproven / conditional / unanswered; the "still unknown" list; "a working artifact is not a proven hypothesis".
- hordev `racing-prototypes`: race only on one axis argument cannot settle; criteria written before the race, judged on behavior; no cherry-picked hybrid; nothing deleted before the operator has seen the comparison.
- why-log: an `operator` decision needs a verbatim quote or a transcript pointer, otherwise it is `open`; the provenance aliases stated in the handoff.
- Continuity, madr-gen, MADR: `supersedes` / `superseded by` by decision id, with the old decision kept as history.
- agent-lab-kit: pre-registration before the scored run (already present) and a cover check that refuses a handoff that dropped something.
- GSD: the first direction is the one most likely to kill the idea.
- gamedev `prototype-fast`, bigpowers: keep criteria beside kill criteria.
- spikekit: the pending-decision idea is what `scout question` already does; the handoff's open-decision rows now carry the question to ask.
- passbaton `human-turn.ts`, why-log `validate.py`, Pocock `/handoff`, Continuity frozen guard: the script checks an `operator` quote verbatim (whitespace-normalized, at least 10 characters) against the human turns of the recorded transcripts, with compaction summaries excluded and slash-command arguments included; operator words travel on stdin (`-`), not inside shell quotes; only an operator decision supersedes an operator decision.
- prp-spike "Making the evidence followable", passbaton decision-index commit stamp: the handoff marks branches missing, without commits or not pushed and transcripts local or missing, refuses a missing scout branch, and each decision records the commit (and dirty flag) its evidence was cited against.
- HASH `ln-spec` units of record, Continuity capture criteria, agent-lab-kit claim-guard, hordev negative control, prp-spike seat: a decision is one choice between live alternatives at one seam, framing and standing instructions are `operator`, and `proved` needs a check seen to fail with the mechanism reverted, named with its seat; the script refuses `proved` without evidence.
- GSD spike depth, prp-spike `spike-report.md`, `evidence.md` and `framing.md`: each verdict is refused without the evidence its kind needs (`proven` an observed decision, `disproven` a repro, `conditional` a blast radius), and the close records which pre-committed criteria fired, as written.
- prp-spike "Track what got faked" and "The stub that hid the hard part": `scout stub` / `unstub`, stubs re-injected after compaction and listed under Still unknown, and the cover check refuses a handoff that drops one; "never mock the unknown part" goes into `think`.
- agent-lab-kit HANDOFF "Failed (do not retry)", Continuity rejected paths, HASH `ln-handoff` diagnostic evidence: the session-start payload carries every closed direction with what it taught and the observation that turned it, and the handoff's direction lines carry both.
- Pocock `prototype` rule 6, gamedev `prototype-fast` "keep authorizes a rewrite", prp-spike Effort line: the handoff states that the scout branch is evidence, never merged, and that the box is not an estimate.

Not borrowed, and why: passbaton's transcript-uuid gating (scout state is repository-level, so re-injecting it in any session of that repository is correct); hordev's token-count budgets (the CLI's `--max-budget-usd` is enforced between turns, prompt text is not); spikekit's deletion of the scratch directory at wrap (pointers, not summaries).


## 1. Bottom line

The gap is real as an integration and false as a premise: the README's "every workflow framework we found assumes the decisions come first" does not survive October 2026, and the "comparison sites literally say use the agent alone for prototypes" line was not located by any of six researchers and should be dropped or sourced. The closest prior art is **spikekit** (same thesis, same explore-then-write-the-design-down shape, dormant, 2 stars), **Wirasm/prp `prp-spike`** (the strongest mechanics: kill criteria frozen to disk, proved/inferred evidence labels, unattended record-and-proceed, worktree isolation, a downstream handoff; 2.2k-star repo), and **GSD `/gsd:spike`** (the most-adopted spec-first framework shipping a build-first spike mode with pivot/abandon and a wrap-up into planning; now at open-gsd/gsd-core, 11k stars). Keep building, but reposition scout-ahead as the boxed, multi-pivot loop plus the provenance-and-handoff seam between spike tools and spec-driven intake, cite those three plus hordev and Pocock's `/prototype` in the README, and borrow prp-spike's evidence labelling, Continuity/madr-gen's `supersedes` vocabulary, why-log's verbatim-quote gate for `operator`, and passbaton's transcript-uuid gating.

## 4. Bearings, feature by feature

- **Box + kill criteria.** Hours box: exists in bigpowers `spike-prototype` (https://github.com/danielvm-git/bigpowers), gamedev `prototype-fast` (https://github.com/gamedev-skills/awesome-gamedev-agent-skills), HASH `ln-spike` (https://github.com/hashintel/brunch), the DEV.to kill-switch post. Kill criteria frozen before the build: exists in prp-spike (https://github.com/Wirasm/prp/blob/main/.agents/skills/prp-spike/SKILL.md), gamedev `prototype-fast` (KEEP IF / KILL IF), antiagree (https://github.com/antiagree/antiagree). Dollar box metered from spawn costs: **novel** as a composition; the cap itself exists natively as `claude -p --max-budget-usd` (https://code.claude.com/docs/en/checkpointing.md set, best-practices "How much it spends").
- **Pivot / supersession.** Supersession left in place with its reason: exists in Continuity (`supersedes`/`superseded_by`/`superseded_reason`, https://github.com/vikcena01/ai-continuity-plugin), agent-lab-kit retraction tags (https://github.com/Campanadas/agent-lab-kit), madr-gen bidirectional `supersedes` (https://github.com/JiHongKim98/madr-gen), passbaton "Replaces / invalidated" column, HASH `ln-spec` "supersession note", hordev per-assumption "superseded by". Pivot as a first-class boundary of a multi-direction loop: closest is GSD's Continue/Pivot/Abandon checkpoint with "Note the pivot in the README" (https://github.com/open-gsd/gsd-core); nobody marks superseded decisions at the pivot. Cheap undo exists natively as `/rewind`, `/branch`, `--fork-session`. Verdict: **novel only in the combination** (ordered directions + supersession marked at pivot).
- **No asking mid-build.** Exists in spikekit `/spike-goal` (park as a pending-decision card with a `TODO(pending-decision: <id>)` stub, https://github.com/gongxh13/spikekit), prp-spike unattended ("record the interpretation chosen and the alternatives rejected, and proceed"), hordev ("Announced, Not Asked"). Parking to a boundary and printing the parked list at pivot/close is scout's specific twist; spikekit's board is the nearest. **Not novel.**
- **Decision recovery with provenance.** Post-hoc recovery from JSONL + diff: exists in madr-gen. Three-way provenance: exists in why-log (`code|testimony|unknown`, https://github.com/oh-namgyu/why-log — refuted as prior art for the plugin, but the enum is a near one-to-one of code/operator/open), antiagree session audit ("Introduced by (user / you) | Verified?"), prp-spike (`proved`/`inferred` + seat), Continuity (confidence). Recovery at a direction's close, tagged operator/code/open with file:line / commit / quote pointers: **novel as a combination**; every piece exists separately.
- **Handoff format.** Fixed-section handoff for a successor: exists in agent-lab-kit HANDOFF.md, bigpowers SPIKE note, HASH `ln-handoff`, GSD wrap-up skill, spikekit `design.md`, agent-kit `SPIKE.md` Handoff section, prp-spike `references/handoff.md`; pointer-not-copy: Pocock `/handoff` (https://github.com/mattpocock/skills). Pre-registration: exists in agent-lab-kit `labkit prereg`, prp-spike (metric fixed before any variant exists), antiagree thresholds. A tool-neutral file that states its mapping onto a ledger provenance enum so settled decisions are not re-asked, carrying optional pre-registration: **novel**; the "distill" step between spike and spec tool has no tooling anywhere found.
- **Variants in worktrees with caps.** Exists in hordev `racing-prototypes` (2-4, own worktree, equal token budget set beforehand, criteria first, losers kept; https://github.com/heffrey/hordev); commodity in Cursor best-of-N (https://cursor.com/blog/agent-best-practices) and Codex `--attempts 2–4`; worktree-per-spike in prp-spike and ultracode-factory. Each arm a separate `claude -p` with CLI-enforced `--max-budget-usd` in sibling worktrees: **novel composition**, built from native `--worktree` and `--max-budget-usd`.
- **Compaction hook.** Exists natively in Claude Code as the SessionStart `compact` matcher (https://code.claude.com/docs/en/context-window); used by Continuity, passbaton (hardened: transcript-uuid gating, https://github.com/leesgit/claude-session-continuity-mcp), agent-lab-kit, session-recharge, timebox. Re-injecting the open scout's state specifically: closest Continuity `resume_context`. **Not novel.**
- **Transcript pointer.** Transcript read by path: madr-gen, the deleted manifest-dev `/adr`; transcript uuid stored and gated: passbaton; path references in a handoff: Pocock `/handoff`. Recording transcript paths in scout state for the successor: not found as such, but it is a few lines over a documented hook payload; call it **unclaimed, not novel**.

## 5. Recommendations (ranked)

1. **Rewrite README paragraph 2 now.** Replace "Every workflow framework we found assumes the decisions come first" with something like: spike modes exist inside spec-first frameworks (GSD, PRP, HASH Ln, superpowers) and a few tools reject the up-front spec outright (spikekit, hordev); all of them are one question → one verdict → feed a spec, and none runs exploration as a boxed, multi-pivot loop whose decisions are recovered with provenance and handed to a different tool. Drop the "comparison sites literally say" sentence unless the brief can produce the URL.
